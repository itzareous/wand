# Wand landing page

A static site (`index.html` + `styles.css` + `assets/`). No build step: open `index.html`, or deploy the folder to any
static host (Vercel, Netlify, GitHub Pages).

- Fonts: Inter (optical sizes) and Instrument Serif from Google Fonts.
- The phone images in `assets/` are real screenshots of the app (from `docs/screenshots/`). Refresh them when the UI changes.
